Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar pull requests y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listas para que elijas una. Incluye tareas de funcionalidades como el filtrado y la paginación, además de mejoras de calidad como la accesibilidad y los estándares de codificación.

## Elige tu entorno

GitHub Copilot te acompaña donde trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente de agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, aptitudes, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [GitHub Copilot app][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en canvases y gestiona incidencias y pull requests de GitHub en la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa los pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
